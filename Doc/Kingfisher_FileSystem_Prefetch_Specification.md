# Kingfisher I/O & Worker先読み（プリフェッチ）アーキテクチャ仕様書

## 1. File System Access API 連携
ユーザーのローカルPCにある連番ファイルを、サーバーを介さずに直接読み書きするセキュアな設計です。

*   **ディレクトリ権限要求**: 初回起動時に `showDirectoryPicker()` を呼び出し、対象フォルダへの永続的なRead/Write権限を取得する。
*   **ファイルリスト構築**: 取得したディレクトリハンドルから、拡張子が `.tga` のファイルを抽出し、ファイル名でソートしてメモリ上の配列として保持する。
*   **直接上書き保存**: 保存時は `createWritable({ keepExistingData: false })` を使用し、ダイアログを出さずにWasmバッファの内容をOS上のファイルへ直接上書き（フラッシュ）する。

## 2. Web Workerによる非同期デコードパイプライン
メインスレッド（UIと描画）をブロックせず、次フレームを瞬時に表示するための裏側処理です。

*   **Worker Pool**: 常に2つのWeb Workerをバックグラウンドで稼働させる。
*   **先読み指示**: 現在の画像（例: `0002.tga`）が表示された瞬間、メインスレッドからWorkerへ「`0003.tga` (次)」と「`0001.tga` (前)」のデコード指示を送信する。
*   **TGAパース**: Worker内でRust(Wasm)を初期化しておき、ファイルハンドルからバイナリを読み込んでRGBA配列に展開する。

## 3. SharedArrayBufferによるゼロコピー転送
Workerで展開した巨大なピクセルデータを、メインスレッド（WebGPU）へ最速で渡す仕組みです。

*   **メモリ共有**: 事前にメインスレッドで `SharedArrayBuffer` を「現在用」「次用」「前用」の3面確保し、Workerへ参照を渡す。
*   **ポインタ切り替え**: ユーザーがPageDown（次へ）を押した際、データのコピーは一切行わず、WebGPUが参照するバッファのポインタを「次用」に切り替えるだけで完了する（処理時間0ms）。
