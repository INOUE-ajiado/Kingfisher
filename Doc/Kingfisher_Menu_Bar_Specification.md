# Kingfisher UI メニューバー機能詳細仕様書

画面上部のメニューバーに配置された各メニュー項目をクリックした際に展開されるプルダウンメニューと、それぞれの詳細な機能・挙動を定義します。

## 1. ファイル (F)
主にファイルの入出力、保存、アプリケーションの基本設定に関わるメニュー群です。

| メニュー項目名 | ショートカット | 機能詳細・挙動 |
| :--- | :--- | :--- |
| **新規作成** | Ctrl+N | 新規キャンバス（セル）を作成する。解像度や画像サイズを指定するダイアログを表示。 |
| **開く** | Ctrl+O | OSのファイル選択ダイアログを開き、TGA, CEL, BMP形式等の画像を読み込む。 |
| **上書き保存** | Ctrl+S | 現在編集中のセルを、元のファイル名と形式で直接上書き保存する（ダイアログ非表示）。 |
| **名前を付けて保存** | Ctrl+Shift+S | 新しいファイル名や形式を指定して保存するダイアログを表示。 |
| **連番出力 / エクスポート** | - | フォルダ内のすべての編集済みセルを指定形式で一括出力（バッチ処理）する。 |
| **スキャナ（TWAIN）入力** | - | 接続されたスキャナから線画を取り込むダイアログを開く（※Web版ではFile API経由のカメラ/画像読み込みで代替）。 |
| **環境設定** | Ctrl+K | カーソル形状、メモリ割り当て、バックアップ間隔、UIカラーなどを設定する総合ダイアログを表示。 |
| **終了** | Alt+F4 | アプリケーションを終了する。未保存の変更がある場合は確認ダイアログを表示。 |

## 2. 編集 (E)
キャンバス上の画像や、選択範囲に対する編集操作を行うメニュー群です。

| メニュー項目名 | ショートカット | 機能詳細・挙動 |
| :--- | :--- | :--- |
| **元に戻す** | Ctrl+Z | 直前の操作（ペイント、消去など）を1段階取り消す（ヒストリバック）。 |
| **やり直し** | Ctrl+Y | 「元に戻す」で取り消した操作を1段階進める。 |
| **切り取り** | Ctrl+X | 選択範囲のピクセルを削除し、クリップボードにコピーする。 |
| **コピー** | Ctrl+C | 選択範囲のピクセルをクリップボードにコピーする。 |
| **貼り付け** | Ctrl+V | クリップボードの画像をキャンバスの別レイヤー（フロート状態）として貼り付ける。 |
| **消去 (クリア)** | Delete | 選択範囲内のピクセルを完全に透明（完全な白）にする。 |
| **すべて選択** | Ctrl+A | キャンバス全体を選択状態にする。 |
| **選択を解除** | Ctrl+D | 現在の選択範囲を解除する。 |
| **領域の反転** | Ctrl+Shift+I | 現在の選択範囲と非選択範囲を反転させる。 |
| **変形・移動** | Ctrl+T | 選択範囲の拡大縮小、回転、自由変形を行うバウンディングボックスを表示する。 |

## 3. 表示 (V)
キャンバス（セルウィンドウ）の表示倍率や、視覚的な補助ツールのON/OFFを制御します。

| メニュー項目名 | ショートカット | 機能詳細・挙動 |
| :--- | :--- | :--- |
| **ズームイン** | Ctrl++ | キャンバスの表示倍率を1段階（例: 100% → 150%）拡大する。 |
| **ズームアウト** | Ctrl+- | キャンバスの表示倍率を1段階（例: 100% → 50%）縮小する。 |
| **等倍表示 (100%)** | Ctrl+1 | キャンバスのピクセルと画面のピクセルを1:1で表示する。 |
| **ウィンドウに合わせる** | Ctrl+0 | 現在のセルウィンドウの枠サイズに合わせて、画像全体が収まるよう自動拡縮する。 |
| **ルーラーを表示** | Ctrl+R | キャンバスの上下左右にピクセル単位の定規（ルーラー）を表示/非表示する。 |
| **グリッドを表示** | - | キャンバス上にマス目（グリッド線）を表示/非表示する。 |
| **アンチエイリアス表示** | - | 表示上のジャギー（ギザギザ）を滑らかに補間してプレビューするかどうかのトグル。 |

## 4. セル (C)
アニメーションの彩色（Paintman）特有の、セル（連番画像）操作や線画処理に関するメニューです。

| メニュー項目名 | ショートカット | 機能詳細・挙動 |
| :--- | :--- | :--- |
| **次のセルへ** | PageDown | 現在のセルを保存し、リスト内の次の連番ファイル（例: 0002 → 0003）を即座に開く。 |
| **前のセルへ** | PageUp | 現在のセルを保存し、リスト内の前の連番ファイル（例: 0002 → 0001）を即座に開く。 |
| **ライトテーブル設定** | - | 前後セルの透過表示（オニオンスキン）の枚数、不透明度、色付け（赤/青など）を設定するダイアログを開く。 |
| **色トレス線の指定** | - | ツールオプションの「含み塗り」で対象とする色（ハイライト線、影線など）のRGB値を厳密に設定・抽出する。 |
| **ゴミ取り (ノイズ除去)** | - | スキャンした線画に残っている孤立したピクセル（ゴミ）を自動検出し、消去または周囲の色で埋める。 |
| **線画の二値化** | - | グレースケールの線画に対し、閾値を設定して白（透明）と黒（実線）の完全な2色に変換する。 |

## 5. ツール (T)
ツールパレットにある機能をメニューからも呼び出せるようにしたものです。

| メニュー項目名 | ショートカット | 機能詳細・挙動 |
| :--- | :--- | :--- |
| **選択ツール** | V / M | 矩形選択、投げ縄、自動選択（マジックワンド）ツールに切り替える。 |
| **ペイント (ブラシ)** | B | 自由線を描画するブラシツールに切り替える。 |
| **塗りつぶし (バケツ)** | F | 閉じた領域を単色で塗りつぶす。隙間閉じや含み塗りの設定が適用される。 |
| **閉領域フィル** | - | 投げ縄で囲んだ領域の内側にある「白（透明）」のピクセルのみを一括で塗りつぶす。 |
| **消しゴム** | E | ドラッグした軌跡のピクセルを透明にする。 |
| **スポイト** | I (Alt) | キャンバス上のピクセル色を取得し、現在の描画色（アクティブカラー）に設定する。 |
| **手のひら (パン)** | H (Space) | ドラッグでキャンバスの表示位置を平行移動させる。 |

## 6. ウィンドウ (W)
PaintmanのMDI（マルチドキュメントインターフェース）における、各パネルや小ウィンドウの表示管理を行います。

| メニュー項目名 | ショートカット | 機能詳細・挙動 |
| :--- | :--- | :--- |
| **重ねて表示 (カスケード)**| - | 開いている複数のセルウィンドウを、少しずつズラして斜めに重ねて配置する。 |
| **並べて表示 (タイル)** | - | 開いている複数のセルウィンドウを、画面内に敷き詰めるように分割配置する。 |
| **すべてのウィンドウを閉じる**| - | 開いているセルウィンドウをすべて閉じる（未保存があれば確認）。 |
| **ツールパレット** | F5 | 画面左部のツールアイコン群のウィンドウを表示/非表示トグル。 |
| **ツールオプション** | F6 | 選択中ツールの詳細設定（隙間閉じpxなど）ウィンドウを表示/非表示トグル。 |
| **カラーチャート** | F7 | パーツごとの色指定パレットウィンドウを表示/非表示トグル。 |
| **ライトテーブル** | F8 | ライトテーブルの制御パネルを表示/非表示トグル。 |
| **ファイルブラウザ** | F9 | フォルダ内のファイルリスト（セルリスト）ウィンドウを表示/非表示トグル。 |

## 7. ヘルプ (H)
マニュアルやバージョン情報を表示します。

| メニュー項目名 | ショートカット | 機能詳細・挙動 |
| :--- | :--- | :--- |
| **トピックの検索** | F1 | 本アプリケーションのWebオンラインマニュアル（使用方法）を開く。 |
| **ショートカット一覧** | - | 全操作のショートカットキー一覧を表示・編集できるダイアログを開く。 |
| **Kingfisher について** | - | アプリケーションのバージョン情報、著作権、およびライセンス情報をダイアログで表示する。 |
