# Kingfisher 色指定TGA参照・仕上げワークフロー詳細仕様書

**Document Version:** 1.0 (Color Spec Workflow Spec)
**Target Feature:** 色指定（カラーモデル）画像を別タブ/別ウィンドウで参照し、高速にスポイト＆ペイントを行う仕上げ機能

---

## 1. 背景と目的（Paintman仕上げフローの再現）

アニメーションの仕上げ（彩色）工程では、各キャラクターの基準となる「色指定データ（着色済みのTGA等）」を開き、そこから色を拾い（スポイト）、未彩色の線画セルに色を塗る（バケツ）という反復作業が発生します。
Paintmanでは、複数のウィンドウ（マルチドキュメント）を並べて表示（タイル表示）することでこの作業を行っていました。

Kingfisherでは、このフローをモダンなUIで再現しつつ、「スポイト後のツール自動復帰」などのアシスト機能を加えて、より高速な彩色環境を構築します。

---

## 2. 追加・拡張されるメニューボタン仕様

この機能を実現するため、メニューバーに以下の機能を追加します。

### 2.1. [ファイル(F)] メニューへの追加
*   **「参照画像として開く (Open as Reference)」**: 
    *   **機能**: 選択した画像（色指定TGAなど）を、編集対象のメインキャンバスではなく、**「参照用ウィンドウ（別タブ）」**として開きます。この画像は編集（上書き）不可のRead-Onlyモードで開かれます。

### 2.2. [ウィンドウ(W)] メニューへの追加（レイアウト制御）
*   **「並べて表示 (垂直分割 / 水平分割)」**:
    *   **機能**: 現在開いている「編集用タブ」と「参照用タブ」を、画面を2分割して同時に表示します。
*   **「参照ウィンドウの切り離し (Float Reference Window)」**:
    *   **機能**: 別タブで開いた色指定画像を、フローティングパネル（移動・リサイズ可能な小窓）としてUI上に浮かせます。カラーチャートパネルの代わりとして、常に画面の隅に置いておく運用が可能です。

---

## 3. 別タブ（参照ウィンドウ）の機能仕様

色指定TGAを表示する「参照ウィンドウ」は、メインの「セルウィンドウ」とは異なる以下の特別な挙動を持ちます。

### 3.1. スポイト特化の操作体系
参照ウィンドウ上では、ツールパレットで何を選択していても、**デフォルトのカーソルが「スポイト」**になります。
*   **左クリック**: クリックしたピクセルの色を取得し、グローバルな「現在のアクティブカラー」を更新します。
*   **右ドラッグ / ホイール**: 画像のパン（移動）とズーム（拡大縮小）を行います（色指定の細かい部分、例えば瞳のハイライトなどを拡大して色を拾うため）。

### 3.2. ツール自動復帰機能（Auto-Revert Tool）
仕上げ作業を最速化するためのオプション機能です。（ツールオプションでON/OFF可能）
1.  ユーザーがメインウィンドウで「バケツ（塗りつぶし）」ツールを使用中。
2.  参照ウィンドウにマウスを移動し、左クリックで色を拾う（スポイト実行）。
3.  マウスをメインウィンドウに戻した瞬間、**自動的に「バケツ」ツールに復帰**している。
（※Paintmanで頻繁に行われる `Alt+クリック` → `クリック` という操作の手間をさらに省きます）

## 4. UI状態管理設計 (Zustand Store)

参照画像とメイン画像の状態を分離して管理します。

```typescript
interface WorkspaceStore {
  // メインの編集用キャンバス状態
  mainCanvas: {
    fileHandle: FileSystemFileHandle | null;
    imageBuffer: SharedArrayBuffer; // Wasm連携用
  };

  // 参照用（色指定）キャンバス状態
  referenceCanvas: {
    isOpen: boolean;
    isFloating: boolean;            // フローティング窓か、分割タブか
    fileHandle: FileSystemFileHandle | null;
    imageBuffer: SharedArrayBuffer; // 読み取り専用
    zoom: number;
    pan: { x: number, y: number };
  };

  // ワークスペースのレイアウト状態
  layoutMode: 'single' | 'split-vertical' | 'split-horizontal';
}
```

## 5. 想定される標準的な仕上げワークフロー

1.  **起動・読み込み**: 
    `ファイル > 開く` で未彩色の `0001.tga` を開く。
    `ファイル > 参照画像として開く` で `Hero_ColorSpec.tga` を開く。
2.  **画面分割**:
    `ウィンドウ > 並べて表示 (垂直分割)` を選択し、左に未彩色セル、右に色指定画像を並べる。
3.  **彩色作業**:
    *   右画面の「髪の毛」をクリック（色が取得される）。
    *   左画面の「髪の毛」の領域をクリック（バケツで塗られる）。
    *   右画面の「肌の影」をクリック（色が取得される）。
    *   左画面の「肌の影」の領域をクリック（バケツで塗られる）。
4.  **セル移動**:
    キーボードの `PageDown` を押すと、左画面（メインセル）だけが `0002.tga` に進む。右画面（色指定）は固定されたまま。
