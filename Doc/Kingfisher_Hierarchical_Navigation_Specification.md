# Kingfisher 階層対応・カットフォルダナビゲーション仕様書

**Document Version:** 1.0 (Hierarchical Navigation Spec)
**Target Feature:** カットフォルダ（ルート）読み込みと、サブディレクトリ（セル）間のシームレスな移動・比較機能

---

## 1. 背景と目的

アニメーション制作現場の標準的なデータ構造（カット袋）では、1つのカットフォルダ（例: `ATO_07_213_r`）の下に、工程やセルごとのサブフォルダ（`_go/`, `_lo/`, `a/`, `b/`, `c/` など）が存在する。
ユーザーが「TGAが入っている末端のフォルダ」を毎回指定するのは非効率であるため、**「カットフォルダのルート」を1回開くだけで、内部の全セル素材にアクセスし、Win A / Win B に自由に割り当てて比較・彩色できる機能**を定義する。

---

## 2. UIレイアウト拡張（ディレクトリ選択）

既存の「統合ファイルブラウザ」の上部に、カットフォルダ全体の情報を管理するセクションと、Win A / Win B それぞれの「表示対象サブフォルダ」を選択するドロップダウン（セレクタ）を追加する。

```text
[ 📁 統合ファイルブラウザ ]                    [ 🔗 連動 OFF ]
--------------------------------------------------------------
📂 ルート: ATO_07_213_r/            [別カットを開く]
--------------------------------------------------------------
 Win A (Orig)        | 連番マージリスト     | Win B (Retake)
 [ _go (原画)   ▼ ]  | (0001〜)             | [ b (Bセル)    ▼ ]
--------------------------------------------------------------
                     | 0001.tga             | 
                     | 0002.tga             | [ b0002.tga ](緑)
 [ b_go0003 ](青)  ▶ | 0003.tga             | 
                     | 0004.tga             | 
                     | 0005.tga             | [ b0005.tga ](緑)
--------------------------------------------------------------
```

### 2.1. コントロールの役割
*   **ルートディレクトリ表示**: 現在開いているカットフォルダの名前を表示。
*   **サブフォルダセレクタ (Win A / Win B)**: 
    *   ルート直下にあるサブディレクトリ（例: `_go`, `a`, `b`, `c`）のリストを表示するドロップダウン。
    *   ユーザーはここで「Win Aには原画(`_go`)」「Win Bには彩色(`b`)」というように、比較したい素材をアサインする。

---

## 3. ディレクトリ解析とTGA抽出アルゴリズム

`File System Access API` を用いてカットフォルダを開いた際の内部処理フロー。

1.  **ルートハンドルの取得**: `showDirectoryPicker()` でカットフォルダ（`ATO_07_213_r/`）の `FileSystemDirectoryHandle` を取得。
2.  **第一階層のスキャン**: ディレクトリ内を非同期イテレータ (`for await (const entry of handle.values())`) で走査し、サブディレクトリのハンドル一覧を取得。
3.  **プレフィルタリング**: サブディレクトリの命名規則（アンダースコア `_` 始まりの管理フォルダや、アルファベット一文字のセルフォルダ）を識別し、セレクタのUI上にソートして配置する。

---

## 4. 異名ファイルの連番マージ（同期）ロジック

原画（`b_go0001.tga`）と彩色済みセル（`b0001.tga`）のように、**プレフィックス（接頭辞）が異なるファイル同士を連動比較**するための高度なマージロジックを実装する。

*   **連番抽出 (RegEx)**: ファイル名から末尾の「数字部分（通常4桁）」を正規表現で抽出する。
    *   例: `b_go0003.tga` $ightarrow$ `0003`
    *   例: `b0003.tga` $ightarrow$ `0003`
*   **統合リストの生成**: 抽出した「連番」をベースインデックスとして、中央カラムのリストを生成する。
*   **ナビゲーション時の挙動**: 中央の「0003」の行をクリックした際、Win Aには `_go/b_go0003.tga` を渡し、Win Bには `b/b0003.tga` を渡すよう裏側でルーティングを行う。

これにより、ファイル名の完全一致に依存せず、アニメ制作の慣例に沿った柔軟なセル連動比較が可能となる。

## 5. 状態管理 (Zustand Store) 拡張

深い階層を管理するため、ストアの構造を以下のように拡張する。

```typescript
interface FileBrowserStore {
  // カットフォルダ（ルート）のハンドル
  rootDirectoryHandle: FileSystemDirectoryHandle | null;
  
  // スキャンされたサブディレクトリのリスト（セレクタ用）
  availableSubDirectories: Array<{
    name: string;
    handle: FileSystemDirectoryHandle;
  }>;
  
  // Win A / Win B で選択中のサブディレクトリ名
  selectedDirA: string | null; // 例: "_go"
  selectedDirB: string | null; // 例: "b"
  
  // 連動設定と現在の連番インデックス
  isLinked: boolean;
  currentFrameNumber: string; // 例: "0001"
}
```

## 6. 特殊フォルダのフォールバック表示（JPEG/参考画像）

カット袋の中には、TGAではなくJPEG（タイムシート `_sheet/ts0001.jpg` やカットメモなど）が含まれるフォルダが存在する。
*   これらを選択した場合、彩色ツール（バケツ等）は自動的に「ロック（使用不可）」状態となり、純粋な「画像ビューア」として機能させる。
*   これにより、メイン画面で彩色を行いつつ、別ウィンドウ（または分割画面）でタイムシートや演出指示書を並べて確認する、完全なペーパーレスワークフローが成立する。
