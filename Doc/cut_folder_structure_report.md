# アニメーション制作 カットフォルダ構成・命名ルール解析レポート

本ドキュメントは、対象ディレクトリ (`ATO_07_213_r`) のフォルダ構造およびファイル命名ルールを解析し、アニメーション制作現場（仕上げ・撮影・作画工程）におけるデジタルカット袋の構成としてまとめたレポートです。

---

## 1. ルートフォルダの命名ルール解析

```text
ATO_07_213_r
```

| 要素 | 値 | 意味 | 補足 |
| :--- | :--- | :--- | :--- |
| **作品識別子** | `ATO` | 作品名・プロジェクト略称 | 作品ごとに定義される固有コード |
| **話数** | `07` | 第7話 (Episode 7) | 話数を表す数字 |
| **カット番号** | `213` | カット213 (Cut 213) | 該当シーンのカット番号 |
| **ステータス** | `_r` | リテイク (Retake / Revision) | 修正・差し替えが発生したカットであることを明示 |

## 3. 各フォルダ・ファイルの役割詳細

### ルート直下の主要参照ファイル
- **`ATO_07_213_r_memo.jpg`**
  - **カットメモ / 指示書**
  - 演出・作画監督・撮影スタッフ向けの注意事項や修正指示、申し送り事項が記載された画像。

### 工程管理フォルダ (アンダースコア付き)
- **`_lo/` (レイアウト / Layout)**
  - 背景と人物・キャラクターの位置関係やカメラワークを示す基本設計図画像 (`lo0001.tga`)。
- **`_sheet/` (タイムシート / Time Sheet)**
  - カット内の動きのタイミング、コマ打ち、セル重ね順、音合わせなどが記録された指示シート画像 (`ts0000.jpg`, `ts0001.jpg`)。
- **`_sheet_r/` (リテイク用タイムシート)**
  - リテイク（修正）時に更新された新しいタイムシート画像。
- **`_go/` (原画データ / Genga Original)**
  - Bセルなどのキーフレーム原画データ (`b_go0001.tga` 〜 `b_go0004.tga`) を格納。

### セル別仕上げ・ペイント素材フォルダ
- **`a/` (Aセル)**: Aセルの彩色済み動画・仕上げ連番 (`a0001.tga` 〜 `a0004.tga`)
- **`b/` (Bセル)**: Bセルの彩色済み動画・仕上げ連番 (`b0001.tga` 〜 `b0030.tga`)
- **`c/` (Cセル)**: Cセルの彩色済み動画・仕上げ連番 (`c0001.tga` 〜 `c0005.tga`)

### スキャン素材・作業アーカイブ
- **`b_c_r_scansozai/` (B・Cセル リテイク用紙スキャン素材)**
  - **`genga_r_sozai/`**: 紙で描かれ、スキャナーで読み込まれた原画リテイク用紙のJPEG画像群 (`20241025161724_00003.jpg` 等)。
  - **`sheet_r_sozai/`**: 紙で修正されたタイムシートのスキャン画像 (`ts0001.jpg`)。

## 4. 命名ルールと運用上の特徴

1. **アンダースコア (`_`) プレフィックスによるソート制御**
   - `_go`, `_lo`, `_sheet`, `_sheet_r` のようにフォルダ名の先頭に `_` を付与することで、ファイルエクスプローラー等で名前順ソートした際に、セルフォルダ (`a`, `b`, `c` ...) よりも**上部に優先配置**されるよう配慮されています。
2. **セル連番の命名規約**
   - 形式: `[セル記号] + [4桁連番]`（例: `a0001.tga`, `b0005.tga`, `lo0001.tga`）
   - PaintMan、Stylos、After Effects、Toon Boom などの各種ツールで連番画像として問題なく自動認識される標準的な命名形式です。
3. **拡張子 (TGA / JPG) の役割分担**
   - **`.tga` (Targa)**: 仕上げ（ペイント）・撮影工程用。Alpha（透過情報）を保持できる非圧縮/標準画像フォーマット。
   - **`.jpg`**: タイムシート、紙スキャン画像、申し送りメモなど、プレビューや閲覧性を重視した参照用フォーマット。

---

## 5. まとめ

対象のフォルダ構造は、アニメーション制作における**「デジタルカット袋」の標準仕様**に沿ったものであり、各工程（作画・仕上げ・撮影・演出・進行）のスタッフが迷わずアクセスできるように整理されています。

特に、修正（リテイク）発生時における手描きスキャン素材 (`b_c_r_scansozai`) と仕上げ完成データ (`b/`, `c/`)、タイムシート (`_sheet_r`) が明確に分離・格納されており、安全かつ効率的なアセット管理が行われています。
