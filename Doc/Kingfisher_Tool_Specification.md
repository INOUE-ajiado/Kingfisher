# Kingfisher ツール機能詳細仕様書

画面左部に配置される「ツールパレット」および、選択したツールに応じて変化する「ツールオプション」の詳細な機能要件定義書です。
Paintmanにおけるクラシックな操作感と、彩色特化のアルゴリズムを完全再現します。

---

## 1. ツールパレット全体仕様
* **レイアウト**: 2列 × 複数行のグリッド状にアイコンが並ぶフローティングウィンドウ。
* **排他制御**: 常にいずれか1つのツールがアクティブ（選択状態）になる。
* **ショートカット**: 各ツールにはキーボードショートカットが割り当てられており、作業中に左手だけでツールを切り替えられる。

---

## 2. 各ツールの機能とツールオプション詳細

### 2.1. 塗りつぶしツール (バケツ)
アニメ彩色（ペイント）において最も使用頻度が高いメインツール。閉じた領域をクリックして単色で塗りつぶす。

* **ショートカット**: `F`
* **機能**: クリックしたピクセルと同じ色の連続する領域を、現在の「描画色」で置き換える。
* **ツールオプション (固有設定)**:
    * **隙間を閉じる (Gap Close)**: `[ON/OFF]` `[ 0 〜 20 px ]`
        * 線画に途切れがある場合でも、指定したピクセル数以下の隙間であれば「閉じている」と判定して液漏れを防ぐ。
    * **色トレス線を含む (Include Trace Line)**: `[ON/OFF]`
        * **対象色指定**: 赤 `[ON/OFF]`, 青 `[ON/OFF]`, 緑 `[ON/OFF]`, カスタム色 `[スポイトで取得]`
        * 指定した色トレス線を「壁」として認識しつつ、塗りつぶし実行時にそのトレス線自体も塗る（線を消す）。
    * **領域の拡張・縮小 (Expand/Contract)**: `[ON/OFF]` `[ -10 〜 10 px ]`
        * 塗りつぶした結果の領域を、指定ピクセル分だけ太らせる（または細らせる）。アンチエイリアスの効いた線画の下に色を潜り込ませる際に使用。
    * **隣接ピクセルのみ (Contiguous)**: `[ON/OFF]`
        * OFFにすると、キャンバス上の「クリックした色と同じ色」のピクセルすべてを一括で塗りつぶす。
    * **不透明度 (Opacity)**: `[ 1 〜 100 % ]`

### 2.2. 閉領域フィル (投げ縄塗り)
細かい塗り残し（白いドット）などを一気に潰すための特殊な塗りつぶしツール。

* **ショートカット**: `U` (または `Alt + F`)
* **機能**: ドラッグして自由な形（投げ縄）で領域を囲むと、その枠線と「元の線画」で囲まれた **未着色（白・透明）のピクセルのみ** を一括で塗りつぶす。すでに塗られている色は上書きされない。
* **ツールオプション**:
    * **対象色 (Target Color)**: `[透明部分のみ / すべてのピクセル]` (基本は透明部分のみ)
    * **色トレス線を含む**: バケツツールと同様。

### 2.3. 選択ツール
画像の一部を選択し、編集（コピー、移動、消去など）の対象を限定するツール。長押しでサブツールを展開。

* **ショートカット**: `M` (矩形), `L` (投げ縄), `W` (自動選択/マジックワンド)
* **サブツール**:
    * **矩形選択**: ドラッグした四角形の範囲を選択。
    * **投げ縄選択**: ドラッグした軌跡で自由な形を選択。
    * **自動選択 (マジックワンド)**: クリックした色と連続する領域を自動選択。
* **ツールオプション (自動選択時)**:
    * **許容誤差 (Tolerance)**: `[ 0 〜 255 ]` (クリックした色とどのくらい近い色まで選択するか)
    * **領域の拡張 (Expand)**: `[ -10 〜 10 px ]`

### 2.4. ペイントツール (ブラシ / 鉛筆)
自由な線を描く、または細かい塗り残しを直接塗るツール。

* **ショートカット**: `B` (ブラシ), `P` (鉛筆)
* **機能**: 
    * **ブラシ**: アンチエイリアス（境界のぼかし）が効いた滑らかな線。
    * **鉛筆**: アンチエイリアスのない、ドットのはっきりした2値の線（アニメの主線修正や細かいハイライト入れに必須）。
* **ツールオプション**:
    * **ブラシサイズ (Size)**: `[ 1 〜 500 px ]`
    * **アンチエイリアス (Anti-alias)**: `[ON/OFF]` (ブラシ時はON固定、鉛筆時はOFF固定)
    * **不透明度 (Opacity)**: `[ 1 〜 100 % ]`

### 2.5. 消しゴムツール
ピクセルを透明色（完全な白）に戻すツール。

* **ショートカット**: `E`
* **機能**: ドラッグした部分を透明にする。
* **ツールオプション**:
    * **ブラシサイズ (Size)**: `[ 1 〜 500 px ]`
    * **ハードネス (Hardness)**: `[ 0 〜 100 % ]` (0で境界がぼやける、100でくっきり消える)

### 2.6. スポイトツール
キャンバス上の色を取得する。

* **ショートカット**: `I` (または ペイント/バケツ使用中に `Alt` キー押下)
* **機能**: クリックしたピクセルのRGB値を取得し、現在の「描画色」にセットする。
* **ツールオプション**:
    * **抽出範囲 (Sample Size)**: `[ 1x1 ピクセル / 3x3 平均 / 5x5 平均 ]`

### 2.7. 手のひらツール (パン)
キャンバスの表示領域を移動する。

* **ショートカット**: `H` (または 任意のツール使用中に `Space` キー押下)
* **機能**: ドラッグに合わせてキャンバスが平行移動する。画像データ自体は移動しない。

### 2.8. ズームツール (虫眼鏡)
キャンバスの表示倍率を変更する。

* **ショートカット**: `Z`
* **機能**:
    * クリックで拡大（ズームイン）。
    * `Alt` + クリック で縮小（ズームアウト）。
    * ドラッグで囲んだ範囲を画面いっぱいに拡大。

## 3. UI連携の技術仕様 (Rust/Wasm連携)
ツールオプション（隙間閉じ、トレス線色など）のUI状態はZustandで管理されるが、**「塗りつぶしツール」「閉領域フィル」が実行された瞬間に、これらの設定値パラメーター群がセットでRust(Wasm)の関数に引数として渡される。**

```typescript
// バケツツール実行時のWasm呼び出しイメージ
wasm.flood_fill(
    x, y, 
    currentColor, 
    options.gapClose ? options.gapClosePx : 0, 
    options.includeTrace ? options.traceColors : []
);
```
