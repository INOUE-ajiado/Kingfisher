# Kingfisher 独自バケツ塗り（隙間閉じ・含み塗り）アルゴリズム詳細設計書

## 1. 隙間閉じ (Gap Closing) アルゴリズム
線画の途切れによる液漏れを防ぐため、Wasm(Rust)内でモルフォロジー演算（膨張・収縮）を応用した事前処理を行います。

*   **ステップ1 (膨張)**: 塗りつぶし開始位置から探索する際、既存の線画ピクセルから半径 $R$ （ユーザー指定の隙間閉じpx）の範囲を仮想的な「壁」として扱う。距離関数 $D(p, q) \le R$ を満たす空白ピクセルを進入禁止とする。
*   **ステップ2 (Flood Fill)**: 仮想的な壁の内側に対して、高速なスキャンライン方式（Scanline Flood Fill）で塗りつぶしを実行。
*   **ステップ3 (収縮)**: 塗りつぶし完了後、ステップ1で拡張した仮想壁のピクセルに本来の着色判定を行い、隙間部分を自然に埋める。

## 2. 含み塗り (Trace Line Inclusion) 判定ロジック
色トレス線（赤や青など）を境界線として認識しつつ、その線自体も塗りつぶすための拡張判定です。

*   **対象色のベクトル判定**: 指定されたトレス色 $T_c$ （例: 赤）と、隣接ピクセル色 $P_c$ のユークリッド距離を計算し、許容誤差 $E$ 以内であればトレス線と判定。
$$ \sqrt{(T_R - P_R)^2 + (T_G - P_G)^2 + (T_B - P_B)^2} \le E $$
*   **侵食ストップ処理**: トレス線と判定されたピクセルは塗りつぶし対象色で上書きするが、**そのピクセルからのさらなる隣接探索（再帰呼び出し）は停止**する。これにより、線を越えた液漏れを防ぐ。

## 3. Rust (WebAssembly) 実装アーキテクチャ
巨大なキャンバスでも遅延ゼロを実現するため、メモリのコピーを発生させません。

*   **インプレース更新**: JavaScript側で確保した `SharedArrayBuffer` のポインタをRustに渡し、Rust側は `&mut [u8]` として直接ピクセルデータを書き換える。
*   **非再帰的アルゴリズム**: コールスタックオーバーフローを防ぐため、再帰関数ではなく独自のヒープベースのスタック（またはキュー）を用いたScanlineアルゴリズムを実装する。
