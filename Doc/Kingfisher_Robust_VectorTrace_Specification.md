# Kingfisher 堅牢ベクタートレース（SVG）アーキテクチャ仕様書

**Document Version:** 1.1 (Robust Vectorization Spec)
**Target Feature:** Web WorkerとRustを連携した非同期・高精度SVGトレース機能

---

## 1. メインスレッド・ブロッキングの解消

同期的な画像解析はUIのフリーズ（カクつき）を引き起こします。これを防ぐため、重い処理をバックグラウンドに完全に分離します。

*   **非同期パイプライン**: 画像解析とSVG構築をWeb Worker内で実行し、メインスレッド（React）の60fps描画を維持します。
*   **ゼロコピー転送**: `Transferable Objects` や `SharedArrayBuffer` を活用し、巨大なTGA画像データをメモリコピーなしでWorkerへ渡します。
*   **タスクキャンセル (Abort)**: スライダー操作などで古い計算が不要になった場合、Worker側の処理を直ちに破棄し、最新値のみを処理させます。

---

## 2. 学術的根拠に基づくトレースロジック

高品質で無駄のないSVGを生成するため、Potraceアルゴリズム等をベースとした以下の数学的アプローチをRust側で実行します。

*   **Marching Squares (輪郭抽出)**: ピクセルグリッドを探索し、同一色領域の境界を閉じたポリゴンとして正確に抽出します。
*   **Ramer-Douglas-Peucker (間引き)**: 設定された許容誤差 $\epsilon$ を基準に、視覚的影響の少ない頂点を数学的に間引き、パスを軽量化します。
*   **Cubic Bezier Fitting (曲線フィッティング)**: 最小二乗法を用い、間引き後の頂点群に対して滑らかな3次ベジェ曲線 $B(t) = (1-t)^3P_0 + 3(1-t)^2tP_1 + 3(1-t)t^2P_2 + t^3P_3$ を当てはめます。

---

## 3. Web Worker通信とUI実装方針

フロントエンドのコンポーネントをクリーンに保ち、保守性を高めるため、専用のカスタムフックを導入します。

*   **カスタムフック化**: `useEffect` による直接処理を廃止し、`useVectorTraceWorker` のようなフックで非同期通信の複雑さを隠蔽します。
*   **状態管理**: Workerから非同期で返却される「処理中フラグ」と「生成済みSVG文字列」のみをReact側で監視・描画します。
