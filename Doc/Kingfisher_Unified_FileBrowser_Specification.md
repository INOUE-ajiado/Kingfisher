# Kingfisher 統合ファイルブラウザUI/UX詳細仕様書（改訂版）

**Document Version:** 2.0 (Refined UI/UX Spec)
**Target Feature:** 2画面独立/連動ナビゲーションに対応した洗練されたファイルブラウザ

---

## 1. デザインコンセプトの刷新

旧仕様の「ステータス文字（済/編）」による状態表示を廃止し、**「選択アクション」と「現在開いているファイル名」を視覚的に統合した3カラムレイアウト**を採用します。
これにより、ユーザーはリストを見るだけで「Win AとWin Bで今どのセルが開かれているか」を直感的に把握でき、かつ独立してセルを切り替えることが可能になります。

---

## 2. 新しいUIレイアウト設計（モックアップ）

中央に「統合されたファイル名リスト」を配置し、その両脇に「Win A用のアクティブ領域」と「Win B用のアクティブ領域」を設けます。

```text
[ 📁 統合ファイルブラウザ ]                    [ 🔗 連動 OFF ]
--------------------------------------------------------------
Dir A: Cut001_Original/
Dir B: Cut001_Retake/
--------------------------------------------------------------
 Win A (Orig)        | 統合ファイル名       | Win B (Retake)
--------------------------------------------------------------
                     | 0001.tga             | 
                     | 0002.tga             | [ 0002.tga ](緑) ◀ Bはここを開いている
 [ 0003.tga ](青)  ▶ | 0003.tga             | 
                     | 0004.tga             | 
                     | 0005.tga             | 
                     | 0006.tga (B 欠落)    | ⚠️ 
--------------------------------------------------------------
```

### 2.1. UIコンポーネントの視覚的ルール
*   **中央カラム (統合ファイル名):** ディレクトリAとBに存在する全ファイル名をマージして昇順表示するベースライン。
*   **左右カラム (Win A / Win B 選択・表示領域):** 
    *   **非アクティブ時:** マウスホバーすると、薄くファイル名と「開く」アイコンが表示され、クリック可能なボタンとして機能する。
    *   **アクティブ（開いている）時:** 該当するファイル名が、各ウィンドウのテーマカラー（例：Win Aはカワセミブルー、Win Bは翡翠グリーン）のブロックとしてハイライト表示される。これにより「済」という文字を使わず、ファイル名そのもので状態を示す。

---

## 3. リンクOFF（独立モード）時の操作仕様

リンク（🔗）がOFFのときは、AとBの画面を完全に独立して操作できます。

### 3.1. マウスによるセル選択
*   **Win Aのセルを変更する:** 左側のカラム（Win A領域）の任意の行をクリックすると、キャンバスのWin Aにそのファイルが即座にロードされ、青いハイライトブロックがその行に移動する。
*   **Win Bのセルを変更する:** 右側のカラム（Win B領域）の任意の行をクリックすると、キャンバスのWin Bにそのファイルが即座にロードされ、緑のハイライトブロックがその行に移動する。
*   **効果:** A画面で原画（`0003.tga`）を固定して見ながら、B画面（彩色データ）だけをポチポチとクリックして切り替えていく、といった操作が極めて直感的に行える。

### 3.2. キーボードによるセル選択
*   キャンバス上でフォーカス（アクティブ）になっているウィンドウに対してのみ、`PageDown` (次へ) / `PageUp` (前へ) のショートカットキーが適用される。
*   ショートカット入力に連動して、ファイルブラウザ上のハイライトブロックも上下に移動する。

---

## 4. リンクON（連動モード）時の操作仕様

リンク（🔗）をONにすると、リテイク比較のための同期モードに切り替わります。

### 4.1. 状態の強制同期
*   リンクをONにした瞬間、Win Bで開かれているファイルインデックスが、強制的にWin Aと同じ行にスナップ（同期）される。
    （例：Aが `0003`、Bが `0001` を開いていた場合、ONにするとBも自動的に `0003` をロードする）

### 4.2. 連動ナビゲーション
*   **マウス操作:** 中央の「統合ファイル名」自体、もしくはいずれかの行をクリックすると、Win AとWin Bの両方がそのファイルへ同時に切り替わる。
*   **キーボード操作:** `PageDown` を押すと、青ブロック（A）と緑ブロック（B）が、手をつないだように同時に下の行へ移動し、キャンバスも同時に切り替わる。

---

## 5. 欠落ファイル（File Not Found）の表現

片方のフォルダにファイルが存在しない場合（例：Bフォルダに `0006.tga` がまだ作られていない場合）も、文字で「欠落」と書くのではなく視覚的に処理します。

*   **表示方法:** 中央のファイル名部分の右横（またはBカラム内）に、控えめな警告アイコン（⚠️ または斜線アイコン）を表示する。
*   **独立モードでのクリック:** 欠落している行のBカラムをクリックしても無視される（またはキャンバスBが「NO DATA」の空状態になる）。
*   **連動モードでの到達:** 連動モードで欠落行に到達した場合、キャンバスBのみ「NO DATA」表示となり、エラーを出さずに処理を継続する。
