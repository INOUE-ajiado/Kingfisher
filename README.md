# 🐦 Kingfisher (キングフィッシャー)
> アニメーション彩色・仕上げ特化型 Web アプリケーション (PaintMan 互換 Web Studio)

Kingfisher は、アニメーション制作におけるセル画像の彩色・仕上げ（ペイント）作業を Web ブラウザ上で高速・直感的に行うプロフェッショナルなアニメ彩色アプリケーションです。

---

## ✨ 主な特徴と機能

- **🎨 高速 TGA 画像処理 & ゼロ・アップロード**
  - File System Access API を採用し、ローカルフォルダ内の `.tga` アニメ連番画像をブラウザから直接読み込み・上書き保存。
- **🪣 PaintMan 互換 彩色特化アルゴリズム**
  - **隙間閉じ (Gap Close 0~20px)**: 線画の切れ目を自動検知し液漏れ防止。
  - **色トレス線を含み塗り / 線を残す**: 赤・青・緑の色トレス線を壁として認識＆塗りつぶし。
  - **領域の拡張 / 縮小 (-10~10px)**: アンチエイリアス線画の下へ色をすべり込ませるモルフォロジー処理。
  - **閉領域フィル (投げ縄塗り)** / **グラデーション塗り** / **二値鉛筆 (Pencil)**
- **💡 プロ仕様ライトテーブル (色分けオニオンスキン & 2画面分割)**
  - 前フレーム（赤） / 次フレーム（青）の色分け半透明合成表示。
  - **2画面分割表示 (Split View)** ＆ 左右連動同期（ページ送り同期・ズームパン同期）。
- **🔍 チェック & 画像補正機能**
  - **未塗り漏れ点滅表示 (Unpainted Area Flash)**: 未塗り透明領域をマゼンタ表示し白ポチを一秒検出。
  - **全セル一括色置換 (Global Color Replace)** / **手動ワンクリックゴミ取り** / **主線平滑化 (Smoothing)** / **黒線・トレス線全自動レイヤー分離**。
- **🌙 ダークモード ＆ Web Workers / WebGPU レンダリング基盤**
