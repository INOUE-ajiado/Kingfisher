Kingfisher++ Studio 仕様書 ＆ 操作マニュアル

WebGPU駆動 アニメーション仕上げ・彩色・検図・デジタルペイント総合スタジオ Ver 2.0

1. アプリケーション概要

Kingfisher（キングフィッシャー）は、プロのアニメーション制作現場における「仕上げ（彩色）」「検図」「動割り」「仕上げ比較修正」の作業効率を劇的に向上させるために開発された、WebGPU駆動の次世代ブラウザ型WebStudioアプリケーションです。

アニメーション特有の TGA（32bit/24bit）フォーマットをネイティブ処理 し、専用ソフトをインストールすることなく、エクスプローラーやFinderからローカルフォルダを直接開いてリアルタイムにセル彩色・比較・修正を行うことができます。

主な仕様と特長

  • WebGPU & WGSL シェーダー処理: 超高速なアルファ抽出、リアルタイムオニオンスキン合成、マルチレイヤーアフィン変換処理を実現。
  • ローカルTGA直接読み書き: File System Access API および webkitdirectory により、ローカルの原画・リテイクフォルダを直接閲覧・一括処理・上書き保存可能。
  • 二画面分割 ＆ 左右連動比較: 原画（Dir A）とリテイク（Dir B）の同一セルを左右に並べ、ズームやパンを完全に同期させて比較検図。
  • 色指定参照 (ColorSpec) ワークフロー: 参照ウィンドウをドッキング/切り離し表示し、スポイト後に直前のペイントツールへ自動復帰（Auto-Revert）する画期的機能。
  • 自動ペグスタビライザー: 理想の3穴タップ位置を全自動検出して画像傾き・平行移動をリアルタイムアフィン補正。

3. ツールバー ＆ 各種機能一覧

左側のツールパレットおよびメニューから呼び出せる各ツールの割り当てと使用方法です。

ツール名 ショートカット 割り当て機能 ＆ 使用目的
バケツ (Fill) F 同色領域を一括塗りつぶし。許容値 (Tolerance) を調整してトレス線囲み内部を迅速彩色。
グラデーション塗り G 2色間を滑らかに塗りつぶし。アニメの影グラデーションや背景処理に使用。
閉領域フィル (Closed Fill) C フリーハンドで囲んだ内側の未塗り領域を一発で塗る。細かな未塗り隙間の穴埋めに最適。
ブラシ (Brush) B アンチエイリアス付きの滑らかな描画線。修正指示書きや自由描画に使用。
鉛筆 (Pencil) P ドット2値の境界線・トレス線修正用鉛筆。境界がクッキリした二値ペイント。
手動ワンクリックゴミ取り N クリックした場所の孤立1〜4ピクセルのノイズゴミをワンクリックで自動消去。
消しゴム (Eraser) E ペイントした色を削除して透明（または指定背景色）に戻す。
スポイト (Eyedropper) Alt / 長押し キャンバス上の色を取得して現在色に設定。参照画面をクリックすると即取得。
手のひら (Pan) Space / 中クリック キャンバスを自由に移動（パン）。ホイール操作で拡大縮小。

💡 仕上げ特有の高速ペイントコマンド

未塗り漏れ点滅表示 (Ctrl+F): 未彩色領域（Alpha=0）を鮮やかなマゼンタ色でチカチカ点滅させ、塗り残しを1ピクセルも見逃さずチェックできます。

主線アルファ抽出 (Unmultiply): 白背景のTGA線画から純粋な線画アルファ成分のみを自動抽出し、透過セル化します。

4. メニューバー機能リファレンス

ファイル (F) メニュー

  • 新規作成 (Ctrl+N): 空白の新規セルキャンバスを作成。
  • フォルダを開く (Open Directory)... (Ctrl+Shift+O): エクスプローラーやFinderからTGA画像が大量に入ったフォルダを選択して直接ロード。
  • 参照画像として開く (Open as Reference)... (Ctrl+O): 色指定画像やTGAパレットを参照ウィンドウに読み込み。
  • 上書き保存 (Ctrl+S): 編集したTGAセルをローカルファイルへ直接上書き保存。

編集 (E) メニュー

  • 元に戻す (Ctrl+Z) / やり直し (Ctrl+Y): 操作履歴を無限段階復元。
  • タップ穴自動検出＆傾き補正 (Peg Stabilizer): セルの3タップ穴位置をカメラ検出して傾きをミリ単位で水平補正。
  • 全セル一括色置換 (Ctrl+H): 指定したカラーHEXをフォルダ内の全セル画像にわたって一括変換。

ヘルプ (H) メニュー

  • 仕様書・取扱説明書: 本マニュアル（仕様書HTML）を新規タブでいつでも閲覧。
  • ショートカット一覧: キーボード操作ガイドダイアログを開く。

5. 統合ファイルブラウザ (Dir A / Dir B)

画面右上のファイルブラウザは、原画フォルダ（Dir A）とリテイク/修正フォルダ（Dir B）の2系統を同時管理する統合型ブラウザです。

  • Open A / Open B ボタン: 任意のローカルフォルダを指定。
  • 連動 ON/OFF トグル: 連動ON時は中央の統合リストをクリックすると左右両方のセルが同期して切り替わります。
  • 欠落表示 (Alert): Dir A にあって Dir B にないセルは一目でわかるように警告アイコンが表示されます。

6. 色指定参照 ＆ 一発スポイト (ColorSpec Workflow)

色指定TGA画像を参照画面として表示し、一発で色を取得して作業効率を高める機能です。

使い方の手順

  1. ファイル > 参照画像として開く... で色指定TGAファイルをロードします。
  2. ウィンドウ メニューから「垂直分割」「水平分割」または「切り離し (Float)」を選択。
  3. 「スポイト後ツール自動復帰 (Auto-Revert)」をONにしておくと、参照画面上でカラーをクリックした瞬間に色を取得し、直前に使っていた塗りつぶしバケツやブラシツールへ自動的に戻ります。

7. オニオンスキン ＆ ライトテーブル

画面最下部のコントロールから、アニメーションの前後フレーム透過重ね合わせ表示が可能です。

設定項目 機能と使用場面
オニオンスキン ON/OFF 前後の動画フレームを半透明でキャンバスに重ねて表示。動きの繋がりチェックに使用。
枚数 (前 / 後) 前0〜5枚、後0〜5枚の表示枚数を動的設定。
表示モード モノクロ(前赤/後青): 前フレームを赤、後フレームを青に単色着色して前後を一目で識別。
ハーフカラー / フルカラー: 元のセルカラーを透過。
不透明度ステップ減衰 1フレーム離れるごとに指定%ずつ透過率を下げ、近いフレームほどクッキリ表示。
個別ライトテーブル (サブレイヤー) 「参照TGAサブレイヤー追加」で任意のTGAを登録し、X/Y位置移動・回転 (Rot) を個別に調整してタップ割り動画の重ね合わせチェックが可能。

8. ペグスタビライザー (理想タップ穴合わせ)

スキャンしたアニメーション用紙のタップ穴（3穴）の位置ズレや傾きをWebGPU画像解析で自動検出し、キャンバス上で完璧な水平位置に補正アフィン変換する高度な機能です。

手動でX/Y/回転角度を微調整することも可能です。
